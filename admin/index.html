Publishing workflow

Make a change safely

  1. Open Pages CMS and select AIASTest / aias-memphis.
  2. Open the appropriate content area and make the edit.
  3. Use a full https:// URL for external links.
  4. Save, then open the public site and verify the result.
  5. If something looks wrong, correct the CMS entry; the previous version remains in GitHub history.
