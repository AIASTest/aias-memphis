Publishing workflow

Make a change safely

  1. Open Pages CMS and select the chapter website repository.
  2. Use Website or Chapter content as appropriate.
  3. Save, then verify the relevant public page.
  4. For member-linked work, verify the relationship in both directions.
  5. Correct repository content in CMS; previous repository versions remain in Git history.
