How editing works

Publishing a change

  1. Open the website editor and sign in.
  2. Select AIASTest / aias-memphis.
  3. Choose the section you want to edit.
  4. Make the change and save it.
  5. Pages CMS commits the update to GitHub; GitHub Pages republishes the site.

Recommended workflow

For chapter leadership

Use the CMS for routine website changes. GitHub should only be needed for structural changes to the website itself. Uploaded website images are stored with the site so future officers inherit the complete content library.
