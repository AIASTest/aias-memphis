This prototype uses Pages CMS as the editing interface. Authentication is handled with GitHub; authorized chapter leaders can edit site text, events, jobs, student projects, leadership information, images, and custom pages.

1. Sign inUse the GitHub account that has access to the chapter website repository.
2. Select the repositoryOpen the AIAS Memphis website repository in Pages CMS.
3. Edit contentChoose Events, Projects, Jobs, Custom Pages, Leadership, or Site Settings.
4. SaveThe CMS commits the change to GitHub. GitHub Pages serves the updated files.
